# เสียงรถมอเตอร์ไซค์

แต่ละคันมีโฟลเดอร์ของตัวเอง (ชื่อตามโมเดล):

| โฟลเดอร์ | รถ |
|---|---|
| `oldscooter/` | Used Scooter |
| `pcx/` | PCX |
| `giorno/` | Giorno (ไม่มีเสียง coast ปล่อยคันเร่งแล้วเป็นเสียง idle ทันที ตั้งใน `NO_COAST`) |
| `wave125/` | Wave 125 (`low` เล่นตั้งแต่ต้นจนจบไฟล์ตอนเร่ง แล้วค่อยเปลี่ยนเป็น `high` ตั้งใน `LOW_ONCE`) |
| `forza350/` | Forza 350 (ตอนนี้ใช้เสียงเดียวกับ `giorno/` ตั้งไว้ใน `SHARE`) |
| `default/` | ใช้กับรถที่ไม่มีไฟล์เสียงของตัวเอง |

ชื่อไฟล์ในแต่ละโฟลเดอร์ (ใส่เท่าที่มี ไม่ครบก็ได้ รองรับ `.ogg` `.wav` `.mp3`):

| ไฟล์ | ใช้ตอนไหน | แบบเสียง |
|---|---|---|
| `idle.ogg` | จอดติดเครื่อง / ขับช้า | วนลูป |
| `low.ogg` | รอบต่ำ-กลาง | วนลูป |
| `high.ogg` | รอบสูง | วนลูป |
| `rev.ogg` | กดเบรกพร้อมบิดคันเร่ง (เร่งเครื่องค้างไว้) | วนลูป |
| `coast.ogg` | ปล่อยคันเร่งตอนรถยังไหลอยู่ | เล่นครั้งเดียว (ถ้าเป็นเสียงยาวคงที่ ใส่ชื่อโฟลเดอร์ใน `COAST_LOOP` ให้วนลูปได้) |
| `start.ogg` | ตอนเข้าเกม / เปลี่ยนรถ / เติมน้ำมันหลังน้ำมันหมด (ตอนนี้ใช้ `default/start.ogg` ทุกคัน) | เล่นครั้งเดียว |
| `horn.ogg` | กดแตร (ปุ่ม H) | เล่นครั้งเดียว |

- ไฟล์ลูปควรยาว 1-3 วินาที ตัดหัวท้ายให้ต่อกันเนียน รอบเครื่องคงที่ตลอดไฟล์
- ถ้ามีไฟล์เดียว ใส่เป็น `low.ogg` เกมจะใช้ไฟล์นั้นทุกช่วงรอบ แล้วปรับ pitch ตามความเร็วให้
- แนะนำ `.ogg` (ไฟล์เล็ก วนลูปเนียน และเล่นบนเว็บได้ดี)
- ถ้าคลิปลูปมีช่วงเร่งรอบตอนต้น ตั้งจุดเริ่มวนใน `LOOP_START` (เช่น PCX: `low` วนจากวินาทีที่ 2)
- ช่วงความเร็วที่เปลี่ยนจากเสียง low เป็น high ปรับที่ `HIGH_FROM` / `HIGH_FULL` (สัดส่วนของความเร็วสูงสุด ตอนนี้ 60% → 85%)
- ระดับเสียงและช่วง pitch ปรับได้ใน `scripts/engine_audio.gd` (`VOLUME_DB`, `PITCH`)

---

Engine sounds per bike: put `idle` / `low` / `high` / `rev` loops and `coast` / `start` / `horn` one-shots
(.ogg/.wav/.mp3, all optional) in the bike's folder. See `scripts/engine_audio.gd`.
